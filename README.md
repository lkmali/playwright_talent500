# Playwright Talent500

This repository contains end-to-end tests for the Talent500 platform using [Playwright](https://playwright.dev/).

## Steps to Run Playwright Tests

1. **Install dependencies:**
   ```
   npm install
   ```

2. **Run Playwright tests:**
   ```
   npm run playwright
   ```

## Setup Node.js Server for Validation Tests

1. Change to the `web` directory:
   ```
   cd web
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the server:
   ```
   npm run start
   ```

## Run UI Tests from Main Repository

1. Make sure you are in the main repository directory.

2. Install dependencies (if not already done):
   ```
   npm install
   ```

3. Run UI tests:
   ```
   npm run test:ui
   ```
